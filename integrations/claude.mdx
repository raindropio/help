[Claude](https://claude.ai/) is an AI assistant by Anthropic. With this integration it can search, read, and organize your bookmarks via [MCP](/integrations/mcp).

## Connecting

Available on all Claude plans, including Free.

<Steps>
	<Step>
		Open [Raindrop.io in the Claude directory](https://claude.ai/directory/raindrop)
	</Step>
	<Step>
		Click **Connect**
	</Step>
	<Step>
		Authorize Raindrop.io in the browser
	</Step>
</Steps>

You only need to connect once. After that Raindrop.io is available in Claude on the web, in the desktop app, and on iOS and Android.

<Tip>Go to [Customize → Connectors](https://claude.ai/customize/connectors), select Raindrop.io and set **Read-only tools** permission to **Always allow** so Claude doesn't ask for confirmation every time.</Tip>

<Note>On Team and Enterprise plans an Owner has to enable Raindrop.io for the organization first. After that each member connects their own Raindrop.io account.</Note>

## Connecting via Claude Code

If you are signed in to Claude Code with your Claude account, Raindrop.io connected in the steps above is already available there.

Otherwise run in terminal:

```bash
claude mcp add --transport http raindrop https://api.raindrop.io/rest/v2/ai/mcp
```
